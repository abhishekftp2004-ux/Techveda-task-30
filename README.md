# Task 30 — Descriptive Statistics (Expanded Edition)

## Project goal
Calculate and explain mean, median, mode, minimum, maximum, range, variance, standard deviation, quartiles, interquartile range (IQR), and percentiles for at least three numerical variables.

## Files
- `student_performance.csv` — 30-row illustrative student dataset.
- `descriptive_statistics.py` — complete, commented Python solution.
- `descriptive_summary.csv` — calculated results.
- `Task30_Descriptive_Statistics_Full_Explanation.pdf` — detailed report with definitions, formulas, worked examples, code walkthrough, interpretation, limitations, common mistakes, and interview Q&A.
- `Task30_Descriptive_Statistics.ipynb` — notebook version of the solution.

## Requirements
Python 3.9 or newer; Pandas and NumPy.
```bash
python -m pip install pandas numpy
```

## Run
Keep the script and CSV in the same folder:
```bash
python descriptive_statistics.py
```
The program prints data checks and statistics, then creates/updates `descriptive_summary.csv`.
